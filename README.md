# 面试鱼塘

当前支持 Supabase 云端账号与存储。桌面接入配置、共享项目边界、邮件回调设置和验证方式见 [SUPABASE.md](SUPABASE.md)。本地 SQLite 模式仍保留，旧数据未自动导入云端。

基于用户提供的原型图开发的桌面优先高保真本地应用。技术栈为 React 19、TypeScript、Vite 6，图标采用 Lucide。

## 启动

双击项目内的 `启动鱼塘.cmd`，浏览器会自动打开。保持启动窗口运行，关闭窗口可停止服务。

也可以在项目目录运行下列命令。

```powershell
npm install
npm run dev
```

需要 Node.js 24.13 或更新的兼容版本。`npm run dev` 同时启动独立 Node 后端（3001）和 Vite 前端（5173）；前端将 `/api` 代理到后端。默认地址为 http://127.0.0.1:5173 。请保持默认开发端口，变更端口需要同步后端允许的 Origin。

```powershell
npm run build
npm start
```

构建命令包含 TypeScript 类型检查。`npm start` 使用独立后端同时提供生产构建与 API，地址 http://127.0.0.1:3001 。如开发后端已运行，可直接访问这个地址。`npm run preview` 仅启动 4173 前端预览，仍需要另行运行 `npm run server`。SQLite 由 Node 内置模块提供，不需要另装数据库；Node 24.13 会显示实验性 API 提示。

## 素材与视觉实现

使用内置 image_gen 工具，参考用户提供的首页、图鉴和日报原型，生成场景、角色和材质等独立视觉资产，并追加 13 张皮肤图集。

- `public/assets/aquarium-scene.png` 为无文字、无界面、无角色的完整鱼缸环境。
- `public/assets/fish-atlas.png` 为透明背景的 12 角色图集。
- `public/assets/daily-parchment.png` 为透明背景的空白卷边纸张材质。

首页鱼群由独立角色组件呈现并带有轻微游动动画。图鉴卡片、顶部用户区、底部导航、所有文字、筛选、关系连线、时间线、日报正文与表单均由 React / CSS / SVG 实现。运行时不使用整张原型截图作为页面。

原始效果图保留在 `reference/` 供后续视觉对照。场景生成提示词记录在 `ASSETS.md`，皮肤完整提示词集记录在 `SKIN-PROMPTS.json`。

投鱼、单鱼档案、议会、设置和通知没有独立的上传效果图，因此沿用现有图片中的配色、玻璃面板、暖金选中态和生成的角色素材延展设计。通用样式在 `src/tokens.css`、`src/styles.css` 和 `src/generated.css`，壳层和通用组件在 `src/App.tsx` 与 `src/components.tsx`。

画布按 1672 × 941 等比缩放，优先服务 16∶9 桌面屏幕。其他比例居中留边，窄屏整体缩放。当前不包含专门的手机重排版。

## 音乐与音效

全局已接入 Kevin MacLeod 的《Dream Culture》（梦幻水感钢琴，70 BPM），默认音乐音量为 18%，交互音效为 22%。点击界面后音乐柔和淡入，页面切换继续播放；离开标签页暂停，返回后恢复。浏览器若阻止播放，可在「声音设置」中点击「开始聆听 / 重试」。

右下角提供音乐与音效的独立图标开关，登录/注册页位于右上角。滑杆按钮打开音量面板，可分别调整两类声音、试听水滴声并查看素材鸣谢。登录后开关与音量保存到账号，游客模式保存到本地浏览器。音效覆盖按钮、导航、角色点击、投鱼保存及账号登录完成，不在悬停时重复播放。

音频保存在 `public/audio/`，授权与来源详见其中的 `CREDITS.md`（音乐 CC BY 4.0，Kenney 音效 CC0）。`src/Soundscape.tsx` 为独立播放器与设置组件，`src/soundscape.css` 为匹配玻璃 UI 的控制条样式。真实媒体文件在运行时本地加载，不依赖外链。

## AI 生成与引导式问答

桌面项目的 `.env.local` 已配置用户提供的 ModelScope Token。Token 仅由独立 Node 后端读取，前端只调用 `/api/ai/interview`。源码包不包含真实 Token；解压到新电脑后复制 `.env.example` 为 `.env.local`，配置自己的 Token，再启动或重启服务。

默认模型 `deepseek-ai/DeepSeek-V4.1-Flash-1017`，使用 `https://api-inference.modelscope.cn/v1` 的兼容接口。模型和 Token 可在 `.env.local` 修改。开发与预览前端通过代理连接独立后端；`npm start` 同时提供生产页面和 API。AI 生成需要登录。单独将 dist 上传到静态托管不会提供认证、数据库或 AI 接口。

上传 PNG/JPEG/WebP 面邀截图或输入面试经历后，AI 提取公司、岗位、部门、日期时间、轮次、形式等信息，未知字段留空。用户逐题选择选项后自动进入下一题，也可自由输入、返回、跳过、关闭后继续或提前结束。每批最多 3 题，最多 3 批后进入核对。核对页可编辑事实与角色故事，只有点击确认入塘才保存。

截图发送到魔搭用于推理，仅保留在当前页面内存，不复制到项目或 localStorage。核对入塘后，事实档案和角色保存于账号对应的服务端数据库。提示词要求不提取联系电话、邮箱、会议链接，并区分 HR 联系人与面试官、时区与实际地点。模型结果仍需用户核对。

后端支持大小/格式限制、允许列表内的同源与 Host 检查、90 秒超时、取消、并发和频率限制。凭证不返回前端，日志不输出截图和 Token。

## 鱼种、性格与固定皮肤

- AI 根据具体面试内容创作名字、性格标签、口头禅与故事；岗位不再套用预设角色人格。
- 鱼种独立等概率随机：12 种，每种约 8.33%。相同产品经理岗位也可得到任何鱼种。
- 每种鱼有 16 款四季幻彩皮肤和 1 款互联网灵感皮肤，共 204 款。
- 确定鱼种后，四季幻彩合计 92%，16 款各 5.75%；互联网灵感为 8%。随机使用 Web Crypto，规则在 `src/birth.mjs`。
- 外观在创建草案中抽取一次，追问、重试及修改文字不重抽。确认入塘后，sprite 与 skin 随鱼保存，刷新不变，界面没有换装入口。
- `#/skins` 是只读皮肤图鉴，浏览和随机预览不会修改任何已创建的鱼。原有示例角色和历史记录保持原外观。
- 互联网系列参考腾讯、字节、阿里、网易、美团、哔哩哔哩、京东、拼多多、滴滴、百度、小米、华为的配色印象，属于灵感创作，不是官方联名。

13 张皮肤素材全部通过内置 image_gen 生成、保留真正的透明通道；未用 CSS 色相旋转代替生成。位于 `public/assets/skins/`，完整提示词、排列和文件映射见 `SKIN-PROMPTS.json`。
